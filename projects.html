    AI agent · Python · 2026

    Nitrova

    A personal AI assistant for Linux (formerly JARVIS). A zero-token router sends each request to the cheapest model that can handle it (a local Ollama model, Groq, Gemini or Claude), and Claude supervises: any risky action a cheaper model proposes is re-planned by it. A policy engine asks before anything risky, a token-saving harness cut input tokens by about 40% in a measured A/B, and it has long-term memory, schedules, Gmail and Calendar, desktop control and local voice.
